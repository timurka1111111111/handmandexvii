# Handmade Marketplace

Структура проекта (пока пустые файлы-заготовки).

## Структура

- index.html — главная страница
- pages/ — остальные страницы (каталог, товар, корзина, оформление заказа, вход, регистрация, профиль, кабинет продавца, о нас, контакты)
- css/ — стили (по одному файлу на раздел)
- js/ — логика (по одному файлу на раздел)
- js/firebase/firebase-config.js — подключение к Firebase (Firestore)
- assets/ — картинки, иконки, шрифты
